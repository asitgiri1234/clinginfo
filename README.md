# Cling Info Tech

Homepage for Cling Info Tech Works Private Limited. It covers the company’s software work — websites, mobile apps, ERPs, and AI — together with the clients, offices, leadership, and reviews published on [clinginfotech.com](https://clinginfotech.com).

## Getting started

Node.js 20 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- `npm run dev` — local site
- `npm run build` — production build
- `npm run start` — serve that build
- `npm run lint` — ESLint

## What is on the page

- Services, selected work, and three ways to work together
- Current tech-focus films already hosted by Cling
- Twelve markets and the published client logos
- Leadership portraits
- The ten testimonials from the public homepage
- Noida, Pune, and Moradabad offices, with a contact form that opens an email to info@clinginfotech.com
- A footer with the public site’s offices (including Guinea), quick links, services list, and contact details

## Stack

Next.js 16 (App Router), React 19, Tailwind CSS 4, and TypeScript.

## Layout

- `src/app/page.tsx` — page sections
- `src/app/layout.tsx` — type and metadata
- `src/data/content.ts` — copy and the published lists
- `src/components` — header, footer, testimonials, offices, and the contact form
- `public` — wordmark, photographs, logos, flags, and portraits
